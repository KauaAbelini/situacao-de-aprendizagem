## Objetivo
O NewsToday é um site de notícias desenvolvido como parte da atividade que fizemos no começo do ano
O objetivo do projeto era de criar um site de noticias, com alguns cards e algumas páginas.

## O que é
O NewsToday apresenta notícias de diferentes áreas, permitindo que o usuário navegue pelo conteúdo e encontre informações de seu interesse.
O site possui uma interface inspirada em portais de notícias, com destaque para tecnologia, economia, esportes e outros assuntos.
Além das notícias exibidas na página inicial, o projeto possui páginas específicas para determinados conteúdos.

## Componentes
  Página inicial
  Exibição de notícias
  Sistema de pesquisa
  Categoria de tecnologia
  Categoria de economia
  Categoria de esportes
  Layout adaptável para diferentes dispositivos
  Exibição de imagens nas notícias
  Links para páginas individuais das notícias
  Seção de notícias mais lidas
  Área de destaque para notícias importantes

## O que foi utilizado
O projeto foi desenvolvido utilizando:

 HTML — estrutura das páginas
 CSS — estilização e layout
 JavaScrip — funcionalidades e interação
 API de notícias — obtenção de notícias de forma dinâmica
